# Greeting Builder

A beginner JavaScript project that generates personalized greetings based on a person's name and time of day.

## Features

- Format a person's full name.
- Generate greetings based on the time of day.
- Combine reusable functions to create a complete greeting.

## Technologies Used

- JavaScript
- HTML

## Example

Input:
- First name: Ava
- Last name: Stone
- Time of day: morning

Output:
Good morning, Ava Stone

## How to Run

1. Download or clone this repository.
2. Open index.html using a browser or VS Code Live Server.
3. Check the browser console to see the results.
